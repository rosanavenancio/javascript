
# Curso de JavaScript - Gustavo Guanabara 🚀

Repositório dedicado aos exercícios, desafios e projetos desenvolvidos durante o curso gratuito de **JavaScript**, ministrado pelo professor **Gustavo Guanabara** no canal [Curso em Vídeo](https://www.cursoemvideo.com/).

---

## 📌 Conteúdo do Curso

* **Fundamentos:** Variáveis, tipos de dados e operadores.
* **DOM (Document Object Model):** Manipulação e eventos de elementos HTML.
* **Estruturas de Controle:** Condicionais (`if/else`, `switch`) e repetições (`while`, `for`).
* **Avançado:** Vetores (Arrays), funções e introdução a objetos.

---

## 🛠️ Tecnologias Utilizadas

* **JavaScript (ES6+)**
* **HTML5 e CSS3**
* **Git & GitHub**
